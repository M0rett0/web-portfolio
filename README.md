# Portfólio Pessoal — Currículo Vivo

Um portfólio desenvolvido como um **currículo vivo**, apresentando minha trajetória, habilidades e projetos de forma interativa e diferente.
O objetivo deste projeto é unir minhas experiências de UI/UX Design e desenvolvimento Front-End.  


## Preview

🔗 Acesse o projeto:  
https://web-portfolio-iota-jet.vercel.app/


## Sobre o projeto

Este portfólio foi pensado para ir além de uma página estática, funcionando como uma vitrine dinâmica da minha evolução como desenvolvedora.

Aqui você encontra:
- Minha trajetória acadêmica e experiências  
- Habilidades técnicas e comportamentais  
- Projetos desenvolvidos 


## Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript  / TypeScript  
- React


## Aprendizados

Durante o desenvolvimento deste projeto, trabalhei principalmente em:

- Boas práticas de UI/UX  
- Estruturação de aplicações web  
- Responsividade e experiência do usuário  
- Criação de interfaces e protótipos
